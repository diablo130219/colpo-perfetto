# Colpo Perfetto - Supabase pronto

Versione collegata a Supabase.

## Render Web Service

Build Command:
```bash
npm install
```

Start Command:
```bash
node server.js
```

Root Directory: vuoto

## Supabase

Tabella usata:
```text
colpo_perfetto_app_state
```

App key:
```text
colpo_perfetto_main
```

Dati salvati:
- progressioni CP
- taccuino
- cassa iniziale

## Note

Non caricare package-lock.json se ti crea problemi su Render.
